# ROADMAP

## Remaining Features

- [ ] Allow users to search for other users by name

## Rejected Features  

- Be able to ignore future friend requests from a specific user (without notifying them)

## UI

- [ ] Be able to selectively hide or show the password
- [ ] Be able to remember passwords for a given amount of time for user convenience
- [ ] Let the user customise how long until their password should become invalidated
- [ ] Let the user decide how to format the combination of display names and usernames (username only, display name only, or both)
- [ ] Be able to add new profiles (requiring a username, a password, and a host address)
- [ ] Be able to remove profiles
